~ Class 4: Reusable Code
Reusable code = a piece of logic that can be used in multiple places without rewriting it.

Hard Coded: 
function calculateCartTotal() {
    return cart.reduce(...);
}

Better:
function calculateTotal(items) {
    return items.reduce(...);
}


function calculateTotal(items) {
    return items.reduce((total, item) => {
        return total + item.price * item.quantity;
    }, 0);
}

calculateTotal(cart);
calculateTotal(wishlist);
calculateTotal(orderItems);
