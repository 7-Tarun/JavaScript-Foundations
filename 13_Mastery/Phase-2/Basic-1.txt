Case Study: Add "Delete Todo" Feature
❌ The Beginner Approach: Click Button → Write Delete Code → Remove DOM Element

💡 The Architecture Mindset
Breaking the feature down into clean, predictable steps:
• Step 1: Define Feature Behavior
    User action: Clicks the delete button.
    System response: Remove todo from state ➔ Re-render UI based on updated state.
    
• Step 2: Identify Required Data
    Need a unique identifier to target the specific todo.
    Data needed: { id: 1, text: "Buy Milk", completed: false }

• Step 3: Define Pure Logic
    Keep the core calculation isolated from the outside world.
    Concept: Takes existing todos and an ID, then returns a new list without that ID.    deleteTodo(todos, id)

• Step 4: Isolate Side Effects
    Identify external operations that are separate from core logic.
    Examples: DOM updates, localStorage synchronization.
